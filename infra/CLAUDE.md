# Infrastructure

- `compose.yaml`, the image files and the Caddy configuration are in this folder (story E01-005). The updater is in `updater/` (story E01-007); its tests run with the server's (`cd server && uv run pytest ../infra/updater/tests`), and `tests/rehearse_update.py` rehearses an update with real containers. The backup is in `backup/` (story E01-008), with `tests/rehearse_backup.py`. The private network (story E01-009) is the `tailscale` container in the `tailnet` profile; `tests/test_tailnet_config.py` checks its settings and `tests/rehearse_tailnet.py` rehearses it with Headscale. The health monitoring (story E01-010) is the `status` container (Gatus) in the `monitoring` profile; `tests/test_status_config.py` checks its settings and `tests/rehearse_status.py` rehearses it with a stand-in for ntfy. The installer is in `../installer/` (story E01-011), with `tests/rehearse_install.py`.
- Containers run as non-root with read-only file systems and health checks. Images and cloned sources are named by tag and digest or commit, and Renovate updates both. Any without a digest or commit is listed by `tools/check_pins.py`, and the pipeline fails.
- Secrets are files mounted under /run/secrets, never environment variables in Compose files and never committed.
